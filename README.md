# AI Trust Chatbot Project

This repository contains the source code and anonymised interaction logs for a dissertation project:
- "The Evaluation of User Trust and Acceptance of ChatGPT-4-Based AI Systems: Developing and Testing an Intelligent Tool for Trust Assessment"

## Overview

This project investigates how users, specifically UK undergraduates, develop trust in AI chatbots through real interactions. A task-based approach was used to analyse user behaviour, trust levels, and reliance on AI-generated responses.
